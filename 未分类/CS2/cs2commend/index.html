CS2 开房联机 & 个人练习指令大全

CS2 开房联机 & 个人练习指令大全

适用场景：自己单机练习/跑图 + 和好友开房联机对战
使用前提：设置 → 游戏 → 启用开发者控制台 → 是，游戏中按 ~ 呼出控制台
核心原则：sv_cheats 1 是所有练习类指令的总开关，开房联机时建议保持 sv_cheats 0
语法标记：[] 可选；<> 必填占位符，范围写作 <最小值~最大值>；{} 枚举选择；() 分组；| 二选一；... 可重复；-- 选项结束符。
表格规则：多值指令分行列出，指令栏用 —— 表示沿用上一条指令；单值指令一行即可。

一、建房与地图管理

指令 值 注释 值注释 是否作弊
map <地图名> 创建本地服务器 需配合 loopback=0 才能联机；地图名见表 否
map <地图名> loopback=0 创建可联机房间 CS2 联机必须加 loopback=0 否
status — 查看服务器 IP 和 SteamID 将 IP 或 SteamID 发给好友用于连接 否
connect <IP地址> 好友进房 替换为房主提供的 IP 否
connect <IP地址>;password <密码> 有密码时进房 密码为房主设置的 sv_password 否
changelevel <地图名> 切换地图 保留当前服务器设置；地图名见表 否
host_workshop_map <地图ID> 下载并托管创意工坊地图 地图 ID 为创意工坊数字 ID 否
host_workshop_collection <合集ID> 托管创意工坊合集 合集 ID 为创意工坊数字 ID 否
