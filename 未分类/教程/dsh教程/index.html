dsh 安装教程（新手向）

适用平台：Windows 10 / 11
目标：从零安装 Node.js，配置 PATH 环境变量，使用 npm 全局安装 dsh，并成功启动 Web 界面。
预计耗时：15 ~ 30 分钟。

一、准备工作

在开始之前，请确认：

  • 你有一台 Windows 电脑，并拥有 管理员权限
  • 网络连接正常
  • 已准备好 DeepSeek API Key（首次启动 dsh 时需要）

提示：dsh 要求 Node.js 版本 ≥ 22.19，推荐直接安装 Node.js 24 LTS。

二、安装 Node.js

2.1 下载 Node.js

  1. 打开 Node.js 官网。
  2. 点击页面上的 LTS 按钮。
  3. 下载 Windows 安装包（.msi 文件）。

注意：请选择 LTS（长期支持版），不要选择 Current 版本。

2.2 安装 Node.js

  1. 双击下载好的 .msi 文件。
  2. 勾选 I accept the terms in the License Agreement，点击 Next。
  3. 安装路径可以保持默认： 也可以自定义，例如：
  4. 关键步骤：确保勾选 Add to PATH。
  5. 对于 Automatically install the necessary tools：
    • 新手建议 不要勾选。
    • 该选项会安装 Python 和 Visual Studio Build Tools，只有编译原生模块时才需要。
  6. 点击 Install，等待安装完成。
  7. 点击 Finish 结束安装。

重要：安装完成后，请 关闭所有已经打开的终端窗口，然后重新打开 PowerShell 或 CMD。

六、常见问题排查

Q1：node --version 低于 v22.19 怎么办？

请前往 Node.js 官网 下载最新 LTS 版本，覆盖安装旧版本。

也可以使用 nvm-windows 管理 Node.js 版本：

Q2：dsh 命令找不到怎么办？

按顺序排查：

  1. 执行 npm config get prefix，确认路径是 D:\nodejs\node_global
  2. 检查系统变量 Path 是否包含 D:\nodejs\node_global
  3. 关闭旧终端，重新打开一个新终端
  4. 重启电脑后再试

七、安装检查清单

安装完成后，请逐项确认：

  • node --version 输出 ≥ v22.19.0
  • npm --version 可以正常输出版本号
  • npm config get prefix 指向 D:\nodejs\node_global
  • 系统变量 Path 已加入 D:\nodejs\node_global
  • dsh --version 可以正常输出版本号
  • dsh web 可以成功启动
  • 浏览器可以打开 http://127.0.0.1:3080

完成！
如果以上检查项全部勾选，说明你已经成功安装并启动了 dsh。
